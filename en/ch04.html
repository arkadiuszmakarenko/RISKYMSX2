Chapter 4: Backup Registers (BKP)

The Backup Registers (BKP) provide 42 16-bit backup data registers, which can be used to store 84 bytes of user data. After the main power supply (VDD) is powered off, this data can still be maintained by VBAT power, unaffected by standby state, system reset, or power reset. In addition, the BKP unit also provides tamper detection management, RTC clock calibration, and pulse output functions.

4.1 Main Features

  • Provides 84 bytes of backup data registers
  • RTC clock calibration function
  • Outputs RTC clock divided by 64, alarm pulse, or second pulse on the PC13 pin
  • Tamper detection (TAMPER) function

4.2 Functional Description

After the microcontroller is reset, access to the backup registers and RTC is disabled. Access to the backup registers must be enabled through the following operations:

  1. Set the PWREN and BKPEN bits of the RCC_PB1PCENR register to enable the operating clocks for power and backup interface;
  2. Set the DBP bit of the power control register PWR_CTLR to enable access to the backup registers and RTC registers.

4.2.1 Backup Data Registers

The backup data registers can be used as general-purpose data storage. Since they retain data under VBAT power when VDD is lost, they can be used to store important or sensitive data. However, this data will be entirely cleared after a tamper event occurs.

4.2.2 Tamper Detection

Tamper detection means that when an external signal is provided (rising edge or falling edge), it indicates that a "tamper event" has occurred, and the hardware will automatically clear important information retained in the current system. This method can increase the security of system information.

When a transition edge appears on the tamper detection pin (depending on the TPAL bit), a tamper event is generated. If the tamper detection interrupt is enabled, a tamper detection interrupt will also be generated at the same time. Whenever a tamper event occurs, all backup data registers will be cleared. In addition, the hardware detection uses a latching method; even when the tamper detection function is not enabled (TPE=0), the system will sample whether a transition edge has occurred, and under the condition selected by the TPAL bit, it will pre-lock the tamper event and trigger the tamper event when the TPE bit is set to 1.

For example: When TPAL=0, if TPE=0 means the function is not enabled, but the TAMPER pin is already at a high level, once TPE=1, an additional tamper event will be generated (the system pre-locked the rising edge). When TPAL=1, if TPE=0 means the function is not enabled, but the TAMPER pin is already at a low level, once TPE=1, an additional tamper event will be generated (the system pre-locked the falling edge).

Therefore, to prevent unnecessary tamper events that would clear the backup registers, it is recommended that at the moment when hardware detection of the tamper pin is desired to start, by writing 1 to the CTE bit of the BKP_TPCSR register, first clear any tamper event that the hardware may have memorized, and ensure that the current state of the tamper detection pin is inactive.

Note: When the VDD power is disconnected, the tamper detection function remains active. To avoid unnecessary resetting of the backup data registers, the TAMPER pin should be connected to the correct logic level externally.

4.2.3 RTC Calibration

This function must be configured to use the tamper detection pin as a regular I/O port. Clear the TPE bit of the BKP_TPCTLR register.

  • Pulse output: Configure the ASOE bit of the BKP_OCTLR register to enable RTC pulse output; set the ASOS bit to select between second pulse output and alarm pulse output.
  • RTC calibration: After configuring the CCO bit of the BKP_OCTLR register, the internal RTC clock will be output to the tamper detection pin (TAMPER) after being divided by 64. Through actual testing, the software cooperates with modifying the CAL[6:0] bits to adjust the clock and calibrate the RTC.

4.2.4 BKP Interface Reset

The BKP domain can be independently powered by VBAT when the VDD main power is off. During application code control of BKP domain register reset, the backup data registers BKP_DATAR1-10, ASOS bit, and ASOE bit are reset under software configuration of the BDRST bit of the RCC_BDCTLR register, and are not affected by the RCC peripheral interface control BKPRST bit.
