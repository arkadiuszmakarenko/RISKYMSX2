Chapter 7: Independent Watchdog (IWDG)

The system includes an Independent Watchdog (IWDG) to detect software faults caused by logic errors and external environmental interference. The IWDG clock source is derived from the LSI and can operate independently of the main program, making it suitable for applications with low precision requirements.

7.1 Main Features

  • 12-bit down-counter
  • Clock source derived from LSI divider; can run in low-power modes
  • Reset condition: counter value decrements to 0

7.2 Functional Description

7.2.1 Principle and Usage

The Independent Watchdog is clocked by the LSI clock, and its function continues to operate normally in Stop and Standby modes. When the watchdog counter decrements to 0, a system reset is generated, so the timeout period is (reload value + 1) clock cycles.

  • Starting the Independent Watchdog
    After system reset, the watchdog is disabled. Writing 0xCCCC to the IWDG_CTLR register starts the watchdog; it cannot be disabled afterwards unless a reset occurs.
    If the hardware Independent Watchdog enable bit (IWDGSW) is enabled in the user option bytes, the IWDG will be permanently enabled after microcontroller reset.
  • Watchdog Configuration
    The watchdog internally contains a 12-bit down-counter. When the counter value reaches 0, a system reset occurs. To enable the IWDG function, the following operations must be performed:
  1. Counting time base: The IWDG clock is sourced from the LSI. Set the LSI divider value via the IWDG_PSCR register to configure the IWDG counting time base. The operation method is to first write 0x5555 to the IWDG_CTLR register, then modify the divider value in the IWDG_PSCR register. The PVU bit in the IWDG_STATR register indicates the divider value update status; the divider value can only be modified and read when the update is complete.
  2. Reload value: Used to update the current counter value of the Independent Watchdog, from which the counter decrements. The operation method is to first write 0x5555 to the IWDG_CTLR register, then modify the IWDG_RLDR register to set the target reload value. The RUV bit in the IWDG_STATR register indicates the reload value update status; the IWDG_RLDR register can only be modified and read when the update is complete.
  3. Watchdog enable: Write 0xCCCC to the IWDG_CTLR register to enable the watchdog function.
  4. Kick (feed) the watchdog: That is, refresh the current counter value before the watchdog counter decrements to 0 to prevent a system reset. Write 0xAAAA to the IWDG_CTLR register to have the hardware load the IWDG_RLDR register value into the watchdog counter. This action must be executed periodically after the watchdog function is enabled, otherwise a watchdog reset will occur.

7.2.2 Debug Mode

When the system enters debug mode, the IWDG counter can be configured to continue running or stop via the debug module registers.
