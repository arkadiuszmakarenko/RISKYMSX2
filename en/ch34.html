Chapter 34: Pseudo-Static Random Access Memory (PSRAM)

The module description in this chapter applies only to the CH32V467 microcontroller product.

The CH32V467 chip, based on the CH32V407, also integrates a 4M or 8M byte extended PSRAM memory. It supports data storage through address and read/write instructions, and supports DMA.

34.1 Main Features

  • 8-bit hardware width, supports 8-bit, 16-bit, or 32-bit random or block read/write
  • Supports up to 300MHz clock rate, supports dual-edge, maximum 600MBps data transfer rate
  • Supports write data masking
  • Supports high-speed read operations via data strobe
  • Supports register-configurable write and read initial latency
  • Supports half-sleep mode and deep sleep mode
