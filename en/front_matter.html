CH32V407 / V467 Application Manual

V1.1

Description

The CH32V407 is an industrial-grade interconnect microcontroller based on the QingKe RISC-V core, supporting zero-wait operation at up to 200 MHz, and supporting the RVV vector instruction set for accelerating computation or parallel processing applications. The CH32V407 integrates 2 sets of USB 2.0 high-speed PHY transceivers (480 Mbps), an Ethernet MAC controller and 10/100 Mbps physical-layer transceiver; built-in dual ADC units, dual DAC units, OPA operational amplifiers and other analog resources; provides 2 sets of 24-channel DMA controllers, SDIO, DVP digital video interface, ARGB, LTDC, FSMC, multiple timer groups, 10 USART serial ports, I2C interfaces, I3C interfaces, 3 SPI groups, 2 I2S groups, CAN interfaces and other rich peripheral resources.

The CH32V467 adds 4 MB or 8 MB of on-chip extended PSRAM memory (with DMA support) on top of the CH32V407.

This manual provides detailed usage information for the CH32V407 and V467 chips for user application development. For device characteristics of the CH32V407 series, please refer to the CH32V407DS0 manual.
