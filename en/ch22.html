Chapter 22: USB High-Speed Host/Device Controller (USBHS)

The chip integrates two sets of USB2.0 high-speed controllers with dual roles of host controller and device controller, and a built-in 480Mbps USB-PHY physical layer transceiver. When acting as a host controller, it can support low-speed, full-speed, and high-speed USB devices. When acting as a device controller, it can be flexibly configured to low-speed, full-speed, or high-speed mode to suit various applications.

22.1 USB Function Description

  • Supports USB 2.1, USB 2.0, USB 1.1, and USB 1.0 protocol specifications
  • Supports USB Host function and USB Device function
  • Supports control transfer, bulk transfer, interrupt transfer, and real-time/isochronous transfer
  • Provides bus reset, suspend, wake-up, and resume functions
  • Host supports high-speed USB HUB
  • All non-0 endpoints support up to 1024-byte data packets, with built-in FIFO, supporting interrupt and DMA
  • Supports USART serial or I2C pin mapping, also usable for two-wire debug

22.2 Register Description

USB-related registers are divided into two parts:

  • USB high-speed device control registers
  • USB high-speed host control registers

The peripheral base address of the USBHS1 module is: 0x40024000;
The peripheral base address of the USBHS2 module is: 0x40023400.
