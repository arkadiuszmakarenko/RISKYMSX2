Chapter 31: Electronic Signature (ESIG)

The electronic signature contains chip identification information: flash memory area capacity and a unique device identifier. It is programmed by the manufacturer into the system storage area of the memory module at the factory, and can be read via SWD (SDI) or application code.

31.1 Functional Description

Flash memory area capacity: Indicates the size available for the user application on the current chip.

Unique device identifier: A 96-bit binary code that is unique to any given microcontroller. Users can only read it and cannot modify it. This unique identification information can be used as a security password for the microcontroller (product), encryption/decryption key, product serial number, etc., to improve system security mechanisms or indicate identity information.

All of the above content can be accessed by users in 8/16/32-bit reads.
