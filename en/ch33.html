Chapter 33: Extended Configuration (EXTEN)

33.1 Extended Configuration

The system provides an EXTEN extended configuration unit (EXTEN_CTR register). This unit uses the HB clock and only performs reset actions during system reset. It mainly includes the following extended control bit functions:

  1. Internal voltage adjustment: The ULLDOTRIM field selects the default value, which can be modified when adjusting performance and power consumption.
  2. Lock-up function monitoring: When the LKUPEN field is enabled, the system's Lock-up condition monitoring is turned on. Once a Lock-up condition occurs, the system performs a software reset and sets the LKUPRST field to 1, which can be cleared by writing 1 after reading.
  3. VDD18 adjustment: The voltage of VDD18 can be configured.
