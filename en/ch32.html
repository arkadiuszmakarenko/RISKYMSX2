32.2 Flash Programming and Security

32.2.1 Two Programming/Erase Methods

  • Standard Programming: This is the default programming method (compatible mode). In this mode, the CPU performs programming in single 2-byte operations, and performs erase and full-chip erase operations in single 4K-byte operations.
  • Fast Programming: This method uses page operations (recommended). After unlocking via a specific sequence, it performs single 256-byte programming, 32K-byte erase, and full-chip erase operations.
Note: FLASH erase/write related functions can only be placed in the zero-wait-region FLASH.

32.2.2 Security — Preventing Illegal Access (Read, Write, Erase)

  • Page write protection
  • Read protection

When the chip is in read-protected state:

  1. Main memory pages 0–15 (4K bytes) are automatically write-protected and are not controlled by the FLASH_WPR register; when read protection is released, all main memory pages are controlled by the FLASH_WPR register.
  2. The system boot code area, SWD or SDI mode, and RAM area cannot erase or program the main memory, except for full-chip erase. The user option bytes area can be erased or programmed. If an attempt is made to release read protection (programming user option bytes), the chip will automatically erase the entire user area.

32.3 FLASH Enhanced Read Mode

The FLASH enhanced read mode is applicable when the user program runs in FLASH (the user code space exceeds the CODE size space configured by the user option byte RAM_CODE_MOD[1:0] bits). Enabling this mode can improve FLASH access efficiency. To enable this mode, set the EHMOD bit of the FLASH_CTLR register to 1; at this point, read the EHMODS bit — if the EHMODS bit is 1, the enhanced read mode has taken effect. To disable this mode, first clear the EHMOD bit to 0, then set RSENACT to 1. The access clock frequency can also be selected by configuring the SCKMOD bit of the FLASH_CTLR register.

Note: When using the FLASH enhanced read mode, please note the following:
  1. Before performing any erase or programming operations on the FLASH (including releasing read protection and other user option byte programming), you must first exit the enhanced read mode, otherwise erase and programming operations will fail.
  2. Before entering stop mode, you must first exit the enhanced read mode, otherwise the stop mode may be abnormal.
  3. After power reset and system reset are completed, the chip automatically exits the enhanced read mode under hardware control.

32.5 Flash Operation Flow

32.5.1 Read Operation

Direct addressing is performed within the universal address space. Any 8/16/32-bit data read operation can access the flash module's content and obtain the corresponding data.

32.5.2 Unlocking Flash

After system reset, the flash controller (FPEC) and FLASH_CTLR register are locked and not accessible. The flash controller module can be unlocked by writing a sequence to the FLASH_KEYR register.

Unlock sequence:

  1. Write KEY1 = 0x45670123 to the FLASH_KEYR register (step 1 must be KEY1);
  2. Write KEY2 = 0xCDEF89AB to the FLASH_KEYR register (step 2 must be KEY2).

The above operations must be executed in order and consecutively; otherwise, they are considered erroneous and will lock the FPEC module and FLASH_CTLR register and generate a bus error until the next system reset.

The flash controller (FPEC) and FLASH_CTLR register can be re-locked by setting the "LOCK" bit of the FLASH_CTLR register to 1.

32.5.3 Main Memory Standard Programming

Standard programming writes 2 bytes at a time. When the PG bit of the FLASH_CTLR register is '1', each half-word (2 bytes) written to the flash address starts a programming operation. Writing any non-half-word data will cause the FPEC to generate a bus error. During programming, the BSY bit is '1'; when programming is complete, the BSY bit is '0' and the EOP bit is '1'.

Note: When the BSY bit is '1', writing to any register is prohibited.
  1. Check the LOCK bit of the FLASH_CTLR register; if it is 1, perform the "Unlock Flash" operation.
  2. Set the PG bit of the FLASH_CTLR register to '1' to enable standard programming mode.
  3. Write the half-word to be programmed to the specified flash address (even address).
  4. Wait for the BSY bit to become '0' or the EOP bit of the FLASH_STATR register to become '1' to indicate programming is complete, then clear the EOP bit to 0.
  5. Check the FLASH_STATR register for errors, or read the programmed address data for verification.
  6. To continue programming, repeat steps 3–5; to finish programming, clear the PG bit to 0.

32.5.4 Main Memory Standard Erase

Flash can be erased by sector (4K bytes) or by full chip.

  1. Check the LOCK bit of the FLASH_CTLR register; if it is 1, perform the "Unlock Flash" operation.
  2. Set the PER bit of the FLASH_CTLR register to '1' to enable sector erase mode.
  3. Write the page header address to be erased to the FLASH_ADDR register.
  4. Set the STRT bit of the FLASH_CTLR register to '1' to start an erase operation.
  5. Wait for the BSY bit to become '0' or the EOP bit of the FLASH_STATR register to become '1' to indicate erase is complete, then clear the EOP bit to 0.
  6. Read the erased page data for verification.
  7. To continue sector erase, repeat steps 3–5; to finish erasing, clear the PER bit to 0.
Note: After successful erase, word read = 0xe339e339, half-word read = 0xe339, even address byte read = 0x39, odd address read = 0xe3.
  1. Check the LOCK bit of the FLASH_CTLR register; if it is 1, perform the "Unlock Flash" operation.
  2. Set the MER bit of the FLASH_CTLR register to '1' to enable full-chip erase mode.
  3. Set the STRT bit of the FLASH_CTLR register to '1' to start the erase operation.
  4. Wait for the BSY bit to become '0' or the EOP bit of the FLASH_STATR register to become '1' to indicate erase is complete, then clear the EOP bit to 0.
  5. Read the erased page data for verification.
  6. Clear the MER bit to 0.

32.5.5 Fast Programming Mode Unlock

The fast programming mode can be unlocked by writing a sequence to the FLASH_MODEKEYR register. After unlocking, the FLOCK bit of the FLASH_CTLR register will be cleared to 0, indicating that fast erase and programming operations can be performed. It can be re-locked by software setting the "FLOCK" bit of the FLASH_CTLR register to 1.

Unlock sequence:

  1. Write KEY1 = 0x45670123 to the FLASH_MODEKEYR register;
  2. Write KEY2 = 0xCDEF89AB to the FLASH_MODEKEYR register.

The above operations must be executed in order and consecutively; otherwise, they are considered erroneous and will lock until the next system reset before they can be unlocked again.

Note: Fast programming operations require unlocking both the "LOCK" and "FLOCK" layers.

32.5.6 Main Memory Fast Programming

Fast programming is performed per page (256 bytes).

  1. Check the LOCK bit of the FLASH_CTLR register; if it is '1', perform the "Unlock Flash" operation.
  2. Check the FLOCK bit of the FLASH_CTLR register; if it is '1', perform the "Fast Programming Mode Unlock" operation.
  3. Check the BSY bit of the FLASH_STATR register to confirm no other programming operations are in progress.
  4. Set the FTPG bit of the FLASH_CTLR register to '1' to enable fast page programming mode.
  5. Write data to the FLASH address using 32-bit mode, for example:
    *(uint32_t*)0x8000000 = 0x12345678;
  6. Wait for the WR_BSY bit of the FLASH_STATR register to become '0', then write the next data.
  7. Repeat steps 5–6 a total of 64 times.
  8. Set the PGSTRT bit of the FLASH_CTLR register to '1' to start fast page programming.
  9. Wait for the BSY bit to become '0' or the EOP bit of the FLASH_STATR register to become '1' to indicate a fast page programming is complete, then clear the EOP bit to 0.
  10. Check the FLASH_STATR register for errors, or read the programmed address data for verification.
  11. To continue fast page programming, repeat steps 5–10; to finish programming, clear the FTPG bit to 0.

32.5.7 Main Memory Fast Erase

Fast erase is performed per block (32K bytes).

  1. Check the LOCK bit of the FLASH_CTLR register; if it is 1, perform the "Unlock Flash" operation.
  2. Check the FLOCK bit of the FLASH_CTLR register; if it is 1, perform the "Fast Programming Mode Unlock" operation.
  3. Check the BSY bit of the FLASH_STATR register to confirm no other programming operations are in progress.
  4. Set the BER32 bit of the FLASH_CTLR register to '1' to enable fast block erase (32K bytes) mode.
  5. Write the starting address of the fast erase block to the FLASH_ADDR register.
  6. Set the STRT bit of the FLASH_CTLR register to '1' to start a fast block erase (32K bytes) operation.
  7. Wait for the BSY bit to become '0' or the EOP bit of the FLASH_STATR register to become '1' to indicate erase is complete, then clear the EOP bit to 0.
  8. Check the FLASH_STATR register for errors, or read the erased page address data for verification.
  9. To continue fast page erase, repeat steps 5–8; to finish erasing, clear the BER32 bit to 0.
Note: After successful erase, word read = 0xe339e339, half-word read = 0xe339, even address byte read = 0x39, odd address read = 0xe3.

32.6.1 User Option Byte Unlock

The user option byte operation can be unlocked by writing a sequence to the FLASH_OBKEYR register. After unlocking, the OBWRE bit of the FLASH_CTLR register will be set to 1, indicating that user option byte erase and programming can be performed. It can be re-locked by software clearing the "OBWRE" bit of the FLASH_CTLR register to 0.

Unlock sequence:

  1. Write KEY1 = 0x45670123 to the FLASH_OBKEYR register;
  2. Write KEY2 = 0xCDEF89AB to the FLASH_OBKEYR register.
Note: User option byte operations require unlocking both the "LOCK" and "OBWRE" layers.

32.6.2 User Option Byte Programming

Only standard programming mode is supported, writing a half-word (2 bytes) at a time. In practice, when programming user option bytes, the FPEC only uses the low byte of the half-word and automatically calculates the high byte (the high byte is the complement of the low byte), then starts the programming operation. This ensures that the option byte and its complement are always correct.

  1. Check the LOCK bit of the FLASH_CTLR register; if it is 1, perform the "Unlock Flash" operation.
  2. Check the BSY bit of the FLASH_STATR register to confirm no other programming operations are in progress.
  3. Check the OBWRE bit of the FLASH_CTLR register; if it is 0, perform the "User Option Byte Unlock" operation.
  4. Set the OBPG bit of the FLASH_CTLR register to '1'.
  5. Write the half-word (2 bytes) to be programmed to the specified address.
  6. Wait for the BSY bit to become '0' or the EOP bit of the FLASH_STATR register to become '1' to indicate programming is complete, then clear the EOP bit to 0.
  7. Read the programmed address data for verification.
  8. To continue programming, repeat steps 5–7; to finish programming, clear the OBPG bit to 0.
Note: When modifying the "read protection" in the option bytes to "non-protected" state, a full-chip erase of the main memory area will be automatically executed. If options other than "read protection" are modified, no full-chip erase operation will occur.

32.6.3 User Option Byte Erase

Directly erase the entire 128-byte user option byte area.

  1. Check the LOCK bit of the FLASH_CTLR register; if it is 1, perform the "Unlock Flash" operation.
  2. Check the BSY bit of the FLASH_STATR register to confirm no programming operation is in progress.
  3. Check the OBWRE bit of the FLASH_CTLR register; if it is 0, perform the "User Option Byte Unlock" operation.
  4. Set the OBER bit of the FLASH_CTLR register to '1', then set the STRT bit of the FLASH_CTLR register to '1' to start user option byte erase.
  5. Wait for the BSY bit to become '0' or the EOP bit of the FLASH_STATR register to become '1' to indicate erase is complete, then clear the EOP bit to 0.
  6. Read the erased address data for verification.
  7. Clear the OBER bit to 0 to finish.
Note: After successful erase, word read = 0xe339e339, half-word read = 0xe339, byte read = 0x39.

32.6.4 Releasing Read Protection

Whether the flash is read-protected is determined by the user option bytes. Reading the FLASH_OBR register, when the RDPRT bit is '1', it indicates the current flash is in read-protected state, and flash operations are subject to a series of security protections of the read-protected state. The process of releasing read protection is as follows:

  1. Erase the entire user option byte area. At this point, the read protection field RDPR still has read protection in effect.
  2. Program the user option bytes, writing the correct RDPR code 0xA5 to release the flash read protection. (This step will first cause the system to automatically perform a full-chip erase operation on the flash.)
  3. Perform a power-on reset to reload the option bytes (including the new RDPR code); at this point, read protection is released.

32.6.5 Releasing Write Protection

Whether the flash is write-protected is determined by the user option bytes. Reading the FLASH_WPR register, each bit represents 4K bytes of flash space. When a bit is '1', it indicates non-write-protected state; when '0', it indicates write-protected. The process of releasing write protection is as follows:

  1. Erase the entire user option byte area.
  2. Write the correct RDPR code 0xA5 to allow read access;
  3. Perform a system reset to reload the option bytes (including the new WRPR[3:0] bytes); write protection is released.
